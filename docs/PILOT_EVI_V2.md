# Информационная ценность виртуального пилота

## Алгоритм

Для каждого α-среза приложение сначала вычисляет минимальное доступное
максимальное сожаление без дополнительной информации. Затем для каждого из не
менее чем 50 воспроизводимых пилотов:

1. задаёт объём `max(2, round(pilot_share·n_analysis))`;
2. генерирует пилотную оценку из текущей асимптотической модели эффекта;
3. объединяет текущую и пилотную оценки по точности;
4. обновляет интервал и графоспецифические достаточные статистики;
5. повторно рассчитывает ценности и минимальное максимальное сожаление;
6. сохраняет неотрицательное сокращение regret.

Чистая EVI равна среднему сокращению regret минус
`pilot_information_cost`. В `DecisionResult` сохраняются:

- `pilot_expected_regret_reduction` — среднее валовое сокращение;
- `pilot_information_value` — чистая EVI;
- `pilot_information_value_se` — внутренняя MCSE;
- `pilot_seed`;
- `pilot_virtual_samples`.

`a1` исключается из допустимых решений, если чистая EVI неположительна. При
неидентифицированной существенной ветви или отсутствии обновляемых стандартных
ошибок EVI считается недоступной, а не подменяется эвристикой ширины интервала.

Контрольные тесты включают положительную EVI с выбором `a1`, неположительную EVI
без выбора пилота и невозможность оценки пилота.
