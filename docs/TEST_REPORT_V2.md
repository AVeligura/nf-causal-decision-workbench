# Отчёт тестирования v2

Дата: 2026-08-17.

## Автоматические проверки

- `ruff check src tests scripts`: PASS.
- `python -m compileall src tests scripts`: PASS.
- Целевая mypy-проверка изменённого научного ядра: PASS.
- 56 не-GUI unit/integration/replay тестов: PASS.
- Из них 28 новых тестов `test_scientific_logic_v2.py`: PASS.
- Контрольные тесты checkpoint/resume Monte Carlo: PASS.
- Экспорты CSV, XLSX, Parquet, JSON, PDF, PNG, SVG и GraphML: PASS.
- `PRAGMA integrity_check` smoke checkpoint: `ok`; 100 completed, 0 duplicate keys.

Новый набор покрывает отсутствие алиаса последнего α-среза, инвариантность
hard-set к μΓ/порядку, структурное переключение, единую ценность, побочные
потенциальные исходы, три состояния EVI пилота, ошибочное `a2`, содержательность
корпуса, ручные параметры, импорт, отсутствие oracle leakage, наименование CATE,
overlap, семантику времени и полный replay.

## UI

Четыре PySide6/pytest-qt теста не выполнены: динамический загрузчик сообщает
`ImportError: libEGL.so.1: cannot open shared object file`. Попытка добавить
локальный Qt runtime была отклонена политикой среды и не обходилась.

Это внешняя блокировка, а не PASS. Реальные скриншоты должны быть получены на
Windows 10/11 либо в Linux-среде с EGL. Статическая компиляция UI-модулей прошла.

## PDF QA

Паспорт отрендерен Poppler в PNG. Первичная проверка выявила выход интервалов за
правую границу. После исправления числового формата и оборачивания ячеек обе
страницы повторно проверены: обрезки, наложения и нечитаемых символов нет.

## Ограничения проверки типов

Полная mypy-проверка всего исторического UI/runtime-кода не считается пройденной:
в проекте остаются внешние stub-проблемы. Существующий стандартный mypy-cache
оказался повреждён (`sqlite3.DatabaseError`); повторный запуск с новым cache-dir,
плагином Pydantic и `--ignore-missing-imports` подтвердил отсутствие ошибок в
восьми изменённых доменных и вычислительных модулях.
