# Формальное определение robust EVI в V3.1

## Объект решения

После первой стадии a1 принимается одно из двух решений: `stop` либо `rollout`
на оставшуюся долю охвата. Для графа `g` обозначим продолженную ценность через
`V_g(d)`. До новых данных используется правило

`R0 = max_d min_g E_g[V_g(d)]`, `d ∈ {stop, rollout}`.

В текущей параметризации `V_g(stop)=0`, а ожидание `V_g(rollout)` определяется
средними ΔCR и ΔCFO ветви, оставшейся долей охвата и дополнительной стоимостью
`program_cost_a2-program_cost_a1`.

## Общее пилотное свидетельство

Для каждого предположения о том, какой граф является истинным, моделируется
один общий результат пилота `z=(z_CR,z_CFO)`. Это два наблюдаемых контраста на
одной виртуальной пилотной выборке. Один и тот же `z` передаётся всем
альтернативным структурам; отдельные псевдонаблюдения для G1, G2, G3 и G4 не
создаются. Ветвь со структурным нулём остаётся фиксированной, остальные
обновляются normal-normal правилом с зарегистрированным `pilot_share`.

После `z` выбирается

`d(z) = argmax_d min_g E_g[V_g(d) | z]`.

Затем ожидание берётся отдельно в каждой возможной истинной ветви и лишь после
этого применяется робастный минимум:

`R1_adaptive = min_g E_{z|g}[V_g(d(z))]`.

Смешение `E[min_g V_g]` и `min_g E[V_g]` исключено. Порядок графов не влияет на
результат: внутренние случайные потоки определяются парой `seed, graph_id`.

## Возможность игнорировать информацию

Участник решения вправе заранее сохранить правило без информации. Поэтому

`R1 = max(R0, R1_adaptive)`.

Если адаптивное правило хуже, в `continuation_with_information_by_graph`
записываются значения исходного stop/rollout. Отсюда по конструкции `R1 ≥ R0`.

`gross EVI = max(0, R1-R0)`;

`net EVI = gross EVI-information cost`.

a1 допустимо тогда и только тогда, когда `net EVI > 0`. Полная графоспецифическая
ценность a1 равна immediate value первой стадии плюс выбранная continuation value
минус information cost. Эти же значения участвуют в max-regret.

Внутренняя MCSE оценивается по виртуальным выплатам графа, задающего минимум
`R1_adaptive`. Она характеризует ошибку вложенного Monte Carlo, в том числе когда
адаптивная информация в итоге игнорируется.

## Обязательный регрессионный пример

При параметрах задания, `seed=1022` и 10 000 виртуальных выборках получено:

- `R0 = 0.003699232173834551`;
- `R1 = 0.005161043675636608`;
- `gross EVI = 0.0014618115018020569`;
- `information cost = 0.0002`;
- `net EVI = 0.0012618115018020568`;
- внутренняя `MCSE = 0.00006531815256476432`.

В V3 сравнивались `gross EVI=0.0054619663`, `R0=0.0037043130` и фактически
использованное `R1=0.0032897443`. В V3.1 противоречие устранено: сообщаемая EVI
равна разности тех же робастных объектов, которые используются в решении.
