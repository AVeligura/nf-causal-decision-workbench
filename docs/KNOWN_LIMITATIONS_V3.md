# Известные ограничения V3

- R3 — контрольный факторный smoke-run на 444 запусках, а не основной эксперимент.
- CATE в R3 преднамеренно отключён; выводы о качестве CATE по R3 не делаются.
- Равное распределение G1–G4 — стресс-тест, не априорные вероятности графов.
- Побочные результаты ценностной модели считаются внешними калиброванными
  параметрами; их отдельная выборочная неопределённость в V3 не оценивается.
- Виртуальный пилот использует нормальное предапостериорное приближение и
  вложенный Monte Carlo; внутренняя MCSE обязательно сообщается.
- outside_gamma содержит ненаблюдаемый фактор и не имеет true_graph_id в Γ.
- GUI-проверки считаются пройденными только при фактическом выполнении в Windows
  или рабочей Qt/EGL-среде с журналами и скриншотами. Заблокированный тест — не pass.
- Полный эксперимент 5000/5000 не выполнялся и требует отдельного разрешения.
