# Ценностная модель V3 и двухэтапный пилот a1

## Единый горизонт

Сравниваются три политики на одном двухстадийном горизонте:

- a0: отказ на всём горизонте, ценность 0;
- a2: полный охват и полная программная стоимость;
- a1: охват `pilot_share` на первой стадии, получение данных, затем выбор stop
  или rollout для оставшейся доли.

Если после a1 выбирается rollout, дополнительная стоимость равна
`program_cost_a2 - program_cost_a1`, поэтому суммарная стоимость совпадает с a2.
Если выбирается stop, остаётся стоимость a1. Ограниченное внедрение не
переименовывается в пилот: обязательна вторая стадия и информационное решение.

## Одна полезность для truth и estimate

Полноохватная полезность до программной стоимости:

`U = multiplier × [ΔCFO + wCR ΔCR + wFC ΔFC + wAR ΔAR − wSales LossSales − wzombie Pzombie]`.

Immediate value a1 равна `pilot_share × U − cost_a1`. Continuation value для
rollout равна `(1-pilot_share) × U − (cost_a2-cost_a1)`; для stop — 0.

## Preposterior EVI

Один вычислитель `evaluate_two_stage_pilot` применяется в истинной и оценочной
ветвях. Для каждого графа он получает текущие средние ΔCR/ΔCFO и их стандартные
ошибки, моделирует латентное состояние и независимую пилотную оценку, выполняет
normal-normal update и выбирает stop/rollout по maximin-критерию. Решение без
новых данных всегда доступно, поэтому информация игнорируется, если её
моделируемая robust value меньше базовой.

- gross EVI: ожидаемый прирост continuation value;
- information cost: отдельный фиксированный компонент;
- net EVI = gross EVI − information cost;
- total a1 = immediate + continuation with information − information cost.

Внутренняя MCSE вычисляется по выборке приращений continuation value. Отчёт
сохраняет immediate, continuation, gross EVI, information cost, net EVI, MCSE,
seed и число внутренних итераций.

Истинная ветвь не копирует EVI из выборочной оценки. Она вызывает тот же
вычислитель с истинными ATE, DGP-известной дисперсией контрастов,
`truth_pilot_seed` и тем же числом внутренних итераций. Оценочная ветвь использует
оценки и стандартные ошибки конкретных структурных ветвей.

a1 исключается из допустимых истинных и оценочных действий при `net EVI ≤ 0`.
Этот инвариант проверяется тестом; при фиксированном seed истинный оптимум и все
компоненты пилота воспроизводятся.
