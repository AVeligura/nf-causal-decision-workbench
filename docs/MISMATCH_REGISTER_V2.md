# Реестр несоответствий v2

| Несоответствие аудита | Исправление | Статус контрольного этапа |
|---|---|---|
| `full_procedure = decisions[-1]` | Введена самостоятельная сводка всей α-траектории и предрегистрированное операционное правило | Исправлено и протестировано |
| Hard-set использовал общую ветвь полной процедуры | Однократный расчёт без μΓ, порядка и истории | Исправлено и протестировано |
| Истинная ценность дублировала и упрощала формулу | Один модуль для оценочных и истинных входов, включая четыре побочных исхода | Исправлено и протестировано |
| Пилотная EVI была эвристикой ширины интервала | 50+ виртуальных пилотов, обновление статистик, gross/net EVI, MCSE, seed | Исправлено и протестировано |
| Корпус свидетельств был графоспецифической калибровкой | Утверждения уровня рёбер, путей и правил из шести типов источников | Исправлено; `0.92/0.81/0.67/0.43` сохранены |
| Ручные параметры сбрасывались пресетом | Пресет применяется однократно, есть пользовательский вариант и reset | Исправлено и параметризованно протестировано |
| Неверное имя CATE-модели | «DR-learner с ExtraTrees по псевдоисходу» | Исправлено |
| Импорт получал паспорт UCI и ложную truth | Метаданные фактического файла, `truth_available=false`, oracle=N/A | Исправлено и протестировано |
| Overlap смешивал true propensity и nuisance | Раздельные min/max истины, extreme share оценки и clipping share весов | Исправлено и протестировано |
| Время всей репликации копировалось как сравнение методов | Разделены replication/shared/method timing; RSS измеряется внутри репликации | Исправлено |
| Replay не проверял траекторию и пилот | Сравниваются эффекты, решения, action sequence, seed, число пилотов и EVI | Исправлено; replay совпал |
| PDF обрезал длинные интервалы | Числа округлены, ячейки оборачиваются, документ повторно отрендерен | Исправлено и визуально проверено |
| `maximum_graph` и oracle совпадали | Кодовые ветви независимы, но текущий DGP по-прежнему задаёт истинный `G1` | Открытый вопрос до полного запуска |
| UI-тесты и реальные скриншоты | Код компилируется, но Qt не загружается без `libEGL.so.1` | Заблокировано окружением |
