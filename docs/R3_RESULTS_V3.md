# Краткие результаты smoke-run R3

R3 завершён: 444/444, failed=0, CATE отключён. SQLite `integrity_check=ok`,
дубликатов design_id нет, в каждой предзарегистрированной подстрате ровно четыре
повтора. Полный эксперимент 5000/5000 не выполнялся.

Истинно оптимальное действие: a0 в 260 запусках и a2 в 184. По режимам:
boundary — 112/36, favorable — 36/112, unfavorable — 112/36 (a0/a2). Тем самым
существовало 260 возможностей ошибочно выбрать a2; ни один метод не сделал
такого выбора, условная частота `erroneous_a2` равна 0. Параметры для получения
ненулевого показателя не подбирались.

Статусы full NF-SCM: robust 0.4775, conditionally robust 0.1194, switching 0,
pilot 0, abstain 0.4032; решение менялось вдоль α-траектории в 0.0541 запусков.
Для maximum/hard/oracle доли robust равны 0.4977/0.5023/0.5090, conditionally
robust — 0.0631/0.0653/0.1171, abstain — 0.4392/0.4324/0.3739.

Средняя gross EVI была 0 для full и hard-set, 0.000005 для maximum graph и
0.000004 для oracle; соответствующая net EVI оставалась отрицательной примерно
−0.001. Поэтому a1 не выбиралось. Это сохранено как результат, а не исправлялось
подбором параметров. Средняя внутренняя MCSE: 0 / 0 / 0.000006 / 0.000004.

Full NF-SCM и hard-set дали одинаковое операционное действие в 90.99% запусков,
но различались в 9.01%; статус различался в 5.41%. Совпадение не трактуется как
обязательное превосходство полной процедуры.

Полные разрезы находятся в `artifacts/experiments/r3-v3/r3_*.csv` и `.json`,
включая сценарий, n, режим, истинный граф и согласованность с max-membership.
