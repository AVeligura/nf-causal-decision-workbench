# Известные ограничения V3.1

- R3.1 — контрольный эксперимент на 444 запусках, не основной Monte Carlo.
- CATE в R3.1 выключен; качество CATE по этим результатам не оценивается.
- Равное представление G1–G4 является стресс-дизайном, а не априорным
  распределением структур.
- Общий пилот описывается нормальным приближением для двух общих контрастов.
  Повторная оценка всех графов на полном виртуальном микродатасете не выполняется.
- Внутренняя MCSE характеризует вложенный Monte Carlo, но не устраняет
  неопределённость самой normal-normal аппроксимации.
- Побочные результаты остаются внешними калиброванными параметрами.
- outside_gamma содержит ненаблюдаемый фактор и не имеет true_graph_id в Γ.
- GUI-runner V3.1 требует Windows либо Linux-среду с рабочими Qt/EGL. В текущем
  контейнере отсутствует `libEGL.so.1`; поэтому фактическая GUI-приёмка здесь
  имеет статус BLOCKED, а не PASS.
- Полный эксперимент 5000/5000 не запускался и требует отдельного разрешения.
