# Исходные данные для тестирования NF-Causal Decision Workbench V3.1.1

Комплект содержит только данные и конфигурацию. Исходный код приложения в него
не включён.

## Состав

- `data/raw/uci_polish/data.csv` — локальная копия UCI Polish Companies
  Bankruptcy, используемая как эмпирический пул ковариат полусинтетического
  генератора;
- `data/raw/uci_polish/ATTRIBUTION.md` — происхождение данных, лицензия и DOI;
- `configs/reference.yaml` — эталонная конфигурация принятой версии V3.1.1;
- `examples/sample_import_reference_seed_20260814.csv` — готовый пример для
  проверки пользовательского импорта через интерфейс приложения;
- `DATA_MANIFEST_SHA256.txt` — контрольные суммы файлов.

## Как использовать

Для обычного эталонного запуска дополнительные действия не требуются: каталог
`data` должен находиться рядом с Windows-приложением в структуре поставки.

Для проверки импорта откройте вкладку «Данные и диагностика», выберите
`examples/sample_import_reference_seed_20260814.csv` и подтвердите автоматически
предложенное сопоставление столбцов. Файл содержит 1500 строк и 15 обязательных
переменных:

`T`, `V`, `L`, `D`, `S`, `Y_CR`, `Y_CFO`, `X1`, `X2`, `X4`, `X5`, `X21`,
`X27`, `X29`, `X44`.

Пример сформирован предзарегистрированным генератором при seed `20260814`.
Oracle truth в файл импорта намеренно не включена: при пользовательском импорте
она должна считаться недоступной.
