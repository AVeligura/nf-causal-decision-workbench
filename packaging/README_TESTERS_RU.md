# NF-Causal Decision Workbench V3.1.1 — комплект тестирования Windows

## Запуск

1. Полностью распакуйте ZIP-архив в обычную пользовательскую папку.
2. Дважды щёлкните `NF_Causal_Workbench.exe`.
3. Windows может показать предупреждение SmartScreen, поскольку тестовая сборка
   не подписана коммерческим сертификатом. Проверьте SHA-256 архива и файла EXE,
   после чего используйте «Подробнее» → «Выполнить в любом случае».

Python и установка пакетов не требуются. Приложение переносимое; результаты и
журналы создаются в каталоге `artifacts` рядом с EXE. Поэтому не размещайте
папку приложения в `Program Files` или другом каталоге без права записи.

## Что проверить

- эталонный одиночный запуск;
- создание лабораторной копии и изменение доступных параметров;
- переходы между пятью рабочими пространствами;
- импорт `sample_import_reference_seed_20260814.csv` из отдельного пакета данных;
- сохранение run ID, закрытие приложения, повторный запуск и replay;
- экспорт таблиц, рисунков и каузального паспорта;
- запуск Neural SCM.

При описании замечания укажите версию Windows, объём оперативной памяти,
последовательность действий, run ID и приложите снимок экрана. Если приложение
не открылось, передайте файл `logs/startup_error.log`.

## Ограничения тестовой сборки

- EXE не имеет цифровой подписи издателя;
- первый запуск может быть медленнее из-за инициализации научных библиотек;
- вычислительное ядро соответствует принятой V3.1.1;
- GUI-сценарий считается пройденным только после фактического выполнения в
  Windows.

Исходные файлы Python, тесты и сценарии сборки в этот комплект не включены.
Нативная компиляция затрудняет извлечение авторской реализации, однако любой
исполняемый код принципиально допускает обратный анализ. Для внешней передачи
рекомендуется дополнить комплект условиями тестирования и запретом
декомпиляции.
