# Автоматическая установка и запуск на Windows

Для обычной работы не нужно вручную вводить команды `pip` или устанавливать
каждый пакет отдельно.

## Первый запуск

1. Полностью распакуйте ZIP-архив в отдельную папку. Не запускайте приложение
   непосредственно из окна архиватора.
2. Убедитесь, что установлен **Python 3.12 x64**. Другие версии Python для этой
   принятой сборки не используются.
3. Дважды щёлкните `INSTALL_AND_RUN.bat`.
4. Дождитесь сообщения об успешной установке. Первый запуск загружает PySide6,
   PyTorch и научные библиотеки, поэтому может занять продолжительное время.
5. После установки приложение откроется автоматически.

Установщик создаёт папку `.venv` рядом с приложением. Системная установка
Python и другие проекты не изменяются. Все действия записываются в
`installation.log`. Версии пакетов берутся из включённого в комплект
`requirements-windows.lock`, сформированного из принятого `uv.lock`.

## Последующие запуски

Снова используйте `INSTALL_AND_RUN.bat`. Если состав зависимостей не менялся,
повторная загрузка пакетов пропускается и приложение запускается сразу.

## Восстановление

Если установка была прервана или один из пакетов повреждён, запустите
`REPAIR_INSTALLATION.bat`. Он повторно проверит и обновит зависимости, сохраняя
репозиторий запусков и результаты приложения.

## Если Python 3.12 не найден

Установите Python 3.12 x64 с официального сайта Python и включите параметр
`Add python.exe to PATH`. После установки снова запустите `INSTALL_AND_RUN.bat`.

## Где хранятся результаты

По умолчанию локальный репозиторий приложения находится в
`artifacts\repository` внутри распакованной папки. Автоматический установщик не
удаляет и не перезаписывает этот каталог.
