# NF-Causal Decision Workbench V3.1.1 — Windows testing build

This prerelease combines the independently accepted computational core V3.1
with GUI revision V3.1.1. The GUI revision changes the acceptance replay path:
a saved run is selected from a newly opened application window. Scientific
formulas, algorithms, parameters, factor plans, and metrics are unchanged.

## Assets

- `NF_Causal_Workbench_V3_1_1_Windows_Tester.zip` — portable Windows 10/11 x64
  application; Python is not required;
- `NF_Causal_Workbench_V3_1_1_Test_Data.zip` — accepted UCI source pool,
  reference configuration, and a sample import file;
- matching `_SHA256.txt` files — SHA-256 checksums generated by the release job.

## Verification performed by the build

- the UCI source file is downloaded from the official endpoint and checked
  against the accepted SHA-256;
- the application is compiled on `windows-latest` with Python 3.12 x64;
- the built EXE runs an autonomous package and data smoke-check;
- the distribution is checked as AMD64 PE and scanned for Python source files;
- all distributed files and both release archives receive SHA-256 manifests.

## Known limitations

- the EXE is not digitally signed and may trigger Windows SmartScreen;
- the first launch may be slower while scientific libraries initialize;
- final GUI acceptance remains pending until the accepted replay scenario is
  completed on Windows or in a working Qt/EGL environment;
- the full 5000/5000 experiment corpus is not included in this user release.
