# Build provenance V3.1.1

V3.1.1 создана как отдельная GUI-версия из принятого source ZIP V3.1.

Изменения ограничены:

- видимым списком сохранённых run ID;
- межоконным GUI acceptance runner;
- документацией, тестом runner и метаданными версии пакета.

Файлы вычислительного ядра `src/engine`, `src/study`, `src/runtime`,
`src/visualization` и вычислительные части `src/domain` совпадают с V3.1.
Поле `RunManifest.app_version` сохранено равным `0.3.1`, чтобы явно обозначить
неизменённое вычислительное ядро; версия GUI-пакета в `pyproject.toml` равна
`0.3.1.1`.

Независимые проверки V3.1.1:

- 78 non-GUI tests: PASS;
- ruff: PASS;
- mypy для 28 файлов вычислительного ядра: PASS;
- фактическая GUI-приёмка: BLOCKED из-за отсутствия `libEGL.so.1` до создания
  `QApplication`; PASS не заявлен, скриншот не создавался.

Авторитетные SHA-256 публикуются только в итоговом внешнем файле
`FINAL_SHA256.txt`. Промежуточные archive SHA в комплект не включаются.
