# GUI acceptance V3.1.1

Status: **BLOCKED**.

Фактический запуск в Linux offscreen Qt остановился до создания `QApplication`:

`ImportError: libEGL.so.1: cannot open shared object file: No such file or directory`

Поэтому межоконный сценарий replay не объявлен `PASS`, а скриншот не создавался.
Runner V3.1.1 подготовлен для фактического выполнения в Windows или рабочей
Qt/EGL-среде. Он выполняет следующие действия через реальные виджеты:

1. сохраняет выполненный запуск;
2. закрывает первое окно;
3. создаёт новое окно на том же репозитории;
4. выбирает сохранённый run ID из видимого списка;
5. запускает replay кнопкой GUI;
6. проверяет совпадение и сохраняет журнал и скриншот только после успеха.

Вычислительное ядро, формулы, параметры полного эксперимента и правила метрик
V3.1 не изменялись.
