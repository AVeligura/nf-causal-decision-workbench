# NF-Causal Decision Workbench

**NF-Causal Decision Workbench** — настольное исследовательское приложение для
анализа решений в условиях причинной и структурной неопределённости. Проект
развивает вычислительные материалы главы 7 коллективной монографии о
нейро-нечётких технологиях моделирования экономических систем.

Текущая публикация объединяет принятое вычислительное ядро **V3.1** и
интерфейс **V3.1.1**. Изменения V3.1.1 относятся только к сценарию GUI replay;
формулы, алгоритмы, параметры и предзарегистрированный экспериментальный дизайн
V3.1 не изменены.

## Возможности

- построение и сравнение причинных графов при структурной неопределённости;
- нечёткая совместимость свидетельств `μΓ(G)` без вероятностной интерпретации;
- графоспецифическая идентификация, оценивание и частичная идентификация;
- α-траектория, robust EVI, regret и операционное решение;
- CATE через DR-learner с ExtraTrees по псевдоисходу;
- Neural SCM, чувствительность и диагностические визуализации;
- импорт CSV/XLSX/Parquet с явным сопоставлением переменных;
- воспроизводимые run packages, SQLite-хранилище, экспорт и replay;
- resumable Monte Carlo с раздельными потоками data, pilot и truth-pilot seeds.

`μΓ(G)` является степенью совместимости структуры со свидетельствами. Она не
нормируется и не используется как вероятность графа или вес причинного эффекта.
Состояния `not_identified`, `partially_identified` и структурный нуль являются
самостоятельными результатами.

## Скачать Windows-сборку

Готовый переносимый пакет находится в разделе
[Releases](https://github.com/AVeligura/nf-causal-decision-workbench/releases).

1. Скачайте `NF_Causal_Workbench_V3_1_1_Windows_Tester.zip` и файл его SHA-256.
2. Проверьте контрольную сумму и полностью распакуйте архив.
3. Запустите `NF_Causal_Workbench.exe`.

Python и установка пакетов для готовой сборки не нужны. Требуется Windows 10/11
x64; рекомендуется не менее 16 ГБ RAM. Сборка пока не подписана сертификатом,
поэтому Windows SmartScreen может показать предупреждение.

Отдельный архив `NF_Causal_Workbench_V3_1_1_Test_Data.zip` содержит исходный
набор UCI, эталонную конфигурацию и пример пользовательского импорта. Полная
инструкция находится внутри обоих архивов.

## Запуск из исходников

Требуется Python 3.12 x64.

```powershell
git clone https://github.com/AVeligura/nf-causal-decision-workbench.git
cd nf-causal-decision-workbench
python scripts/fetch_uci_data.py
INSTALL_AND_RUN.bat
```

`INSTALL_AND_RUN.bat` создаёт локальное окружение `.venv`, устанавливает
зафиксированные зависимости и запускает приложение. Для PyCharm выберите
интерпретатор `.venv\Scripts\python.exe` и запускайте `launcher.py` из корня
проекта. Подробности: [README_AUTOINSTALL_RU.md](README_AUTOINSTALL_RU.md).

## Научная воспроизводимость

Эталонные определения, факторный план и ограничения зафиксированы в каталоге
[`docs`](docs). Основные точки входа:

```powershell
$env:PYTHONPATH="src"
.venv\Scripts\python scripts\run_reference.py
.venv\Scripts\python scripts\run_control_examples.py
.venv\Scripts\python -m pytest
```

Полный дизайн 5000/5000 программно требует явных флагов авторизации и не
запускается автоматически при сборке приложения. Полный экспериментальный
корпус и промежуточные результаты в репозиторий и пользовательский Release не
включаются.

## Данные

Полусинтетический генератор использует
[UCI Polish Companies Bankruptcy](https://doi.org/10.24432/C5F600) как
эмпирический пул ковариат. Набор распространяется по CC BY 4.0. Скрипт
`scripts/fetch_uci_data.py` скачивает файл с официального источника и принимает
его только при SHA-256
`afbfbed015d20f8421c32c62db37367c018eb6e92b00ea62a23354af8f84c44e`.
Подробности приведены в
[`data/raw/uci_polish/ATTRIBUTION.md`](data/raw/uci_polish/ATTRIBUTION.md).

## Статус приёмки

- вычислительное ядро V3.1 и контрольный эксперимент R3.1 прошли независимую
  приёмку;
- V3.1.1 сохраняет хеши вычислительных модулей V3.1;
- автоматическая Windows-сборка выполняет автономный smoke-check и проверяет,
  что пользовательский ZIP не содержит Python-исходников;
- окончательный GUI `PASS` требует фактического запуска принятого сценария в
  Windows или рабочей Qt/EGL-среде; до этого GitHub Release маркируется как
  prerelease.
