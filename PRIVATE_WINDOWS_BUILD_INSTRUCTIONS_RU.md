# Закрытый комплект сборки Windows

Этот каталог содержит авторский исходный код и предназначен только для
владельца проекта. Коллегам следует передавать исключительно итоговый архив из
папки `release`.

## Локальная сборка

Требования: Windows 10/11 x64, Python 3.12 x64, доступ к интернету, не менее
30 ГБ свободного места. Желательно 16 ГБ оперативной памяти или больше.

1. Полностью распакуйте закрытый комплект.
2. Запустите `BUILD_WINDOWS_TESTER_PACKAGE.bat`.
3. Дождитесь завершения. Установка библиотек и компиляция PyTorch, Qt и научного
   стека могут занять продолжительное время.
4. Передавайте коллегам только:
   - `release/NF_Causal_Workbench_V3_1_1_Windows_Tester.zip`;
   - `release/NF_Causal_Workbench_V3_1_1_Windows_Tester_SHA256.txt`;
   - отдельный архив исходных данных для тестирования.

Скрипт автоматически создаёт отдельное окружение `.build_venv`, выполняет
нативную standalone-компиляцию Nuitka, запускает smoke-проверку собранного EXE,
проверяет архитектуру PE AMD64, отсутствие файлов `.py` и формирует SHA-256.

## Облачная сборка

В комплект включён workflow `.github/workflows/build-windows-tester.yml`. Его
можно запускать только в закрытом репозитории: публикация этого каталога в
открытом репозитории раскроет исходный код. После успешного запуска итоговый
архив доступен как временный artifact workflow.

Нативная компиляция исключает передачу исходных `.py`, но не обеспечивает
абсолютной защиты от реверс-инжиниринга. Для внешнего тестирования рекомендуется
сопроводить поставку письменным запретом декомпиляции и распространения.
